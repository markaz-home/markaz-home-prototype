# Authentication provider assets

These files are based on official provider assets used in the customer auth UI:

- `uae-pass.svg`: UAE PASS round black active logo-only button from the official
  [UAE PASS SVG button assets](https://docs.uaepass.ae/guidelines/design-guidelines/uaepass-button-guideline).
- `google.svg`: the multicolour Google mark from Google's dark square icon-only
  Android/Web asset. The asset's inner button fill and stroke were removed so
  the MARKAZ button supplies the one required outer boundary; the Google mark
  itself remains unchanged. Source: official
  [Sign in with Google branding assets](https://developers.google.com/identity/branding-guidelines#download-brand-icons).

Do not recolour or redraw either mark. If a provider publishes updated
assets or guidelines, replace the corresponding file from that provider's source.
